<h1>Security Policy</h1>

<h2>Reporting a Vulnerability</h2>

<p>If you discover a security vulnerability in this project, please report it privately by emailing <a href="mailto:x@xscriptor">x@xscriptor</a>.</p>

<p>Do not open a public issue for security-related concerns.</p>

<h2>What to Include</h2>

<ul>
  <li>Description of the vulnerability</li>
  <li>Steps to reproduce</li>
  <li>Potential impact</li>
  <li>Any suggested remediation (optional)</li>
</ul>

<h2>Response Timeline</h2>

<p>You can expect an acknowledgment within 48 hours, followed by a fix or mitigation plan within 7 days.</p>

<h2>Scope</h2>

<p>This project provides themes and configurations for OpenCode. Vulnerabilities related to the OpenCode application itself should be reported to <a href="https://github.com/anomalyco/opencode/security">the OpenCode project</a>.</p>
