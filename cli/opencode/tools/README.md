<h1>Tools (Experimental)</h1>

<p>This directory is in an <strong>experimental</strong> phase. Content may change, break, or be removed without notice.</p>

<p>The goal is to provide utility scripts and tooling around the theme ecosystem.</p>

<h2>Planned Tools</h2>

<ul>
  <li><strong>preview-generator</strong> - Generate HTML/image previews of each theme for documentation</li>
  <li><strong>palette-extractor</strong> - Extract dominant colors from images to create new themes</li>
  <li><strong>theme-converter</strong> - Convert between OpenCode theme format and other formats</li>
  <li><strong>validator</strong> - Validate theme JSON files against the OpenCode schema</li>
  <li><strong>batch-installer</strong> - Install themes across multiple tools (opencode, terminal, editor)</li>
</ul>
