<h1>Ports (Experimental)</h1>

<p>This directory is in an <strong>experimental</strong> phase. Content may change, break, or be removed without notice.</p>

<p>The goal is to port the Xscriptor color palettes to other terminals, editors, and tools beyond OpenCode.</p>

<h2>Planned Ports</h2>

<h3>Terminal Emulators</h3>

<ul>
  <li><strong>iTerm2</strong> - Dynamic color profiles (.itermcolors)</li>
  <li><strong>Kitty</strong> - Kitty color configuration (.conf)</li>
  <li><strong>WezTerm</strong> - WezTerm color schemes</li>
  <li><strong>Alacritty</strong> - Alacritty color config (YAML)</li>
  <li><strong>Ghostty</strong> - Ghostty terminal themes</li>
  <li><strong>Windows Terminal</strong> - JSON color schemes</li>
</ul>

<h3>Editors</h3>

<ul>
  <li><strong>VS Code</strong> - VS Code theme extensions</li>
  <li><strong>JetBrains</strong> - IntelliJ IDEA .icls color schemes</li>
  <li><strong>Sublime Text</strong> - Sublime color schemes</li>
</ul>

<h3>Other</h3>

<ul>
  <li><strong>tmux</strong> - tmux status line colors</li>
  <li><strong>bat</strong> - Bat syntax highlighting theme</li>
  <li><strong>delta</strong> - Git diff viewer theme</li>
</ul>
